📑 DOCUMENTO MAESTRO 1: El Tablón de la Verdad (Core de Seguridad)
Componente Técnico,Especificación Operativa (Estándar Local Estricto en Cliente)
Capa 1: Ingress (Lobster Trap),"Inspección determinista ligera (Regex) que analiza el HTML crudo obtenido por Bright Data directamente en memoria. Si encuentra anomalías, activa un testigo visual de riesgo en la interfaz, pero no bloquea el flujo, asumiendo que la evasión en la entrada es siempre una posibilidad."
Capa 2: Inferencia (Agente Local),"Inferencia Privada Nativa: Ejecución del LLM (phi-4-mini / llama-3) directamente en el navegador del cliente mediante WebGPU / WebLLM. El modelo procesa el HTML localmente y genera una invocación de herramienta insegura tras verse influenciado por el contexto externo contaminado (Indirect Prompt Injection), sin riesgo de fugas de datos hacia APIs de terceros."
"El ""Approval Gap"" (El Dolor)","El entorno empresarial tradicional da luz verde a la acción porque el agente posee el permiso semántico de ejecución para el comando (git_add), pero carece de un pipeline estructurado para verificar el impacto físico real de los argumentos sobre la máquina local."
Contrato de Configuración (Real),"Archivo policy.yaml estructurado fidedignamente bajo el esquema del repositorio nativo de Lobster Trap (rules, type: ""regex"", patterns, action: ""quarantine"")."
Capa 3: Egress Core (Pyodide),"Post-Compromise Capability Enforcement Boundary: Motor en Python ejecutado mediante WebAssembly en la pestaña del cliente. Parsea la política de Lobster Trap e intercepta la llamada JSON mid-flight, cortando la acción ante una violación del contrato de límites de capacidad autorizados (../../.env) de forma local y síncrona."
